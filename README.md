# Applied Script – Projektarbete (Grupp 8)

Projektarbete i kursen Applied Script, genomfört i grupp (Grupp 8).

## Om projektet

Projektet innehåller två delar:

- Ett boksystem med ett Data Access Object-lager (`book.py`, `book_dao.py`) för att hantera ett bokregister.
- Ett verktyg för nätverkskonfiguration (`network_config_manager.py`).

Automatiserade tester finns i mappen `tests/`.

## Teknik

- Python

